Vireo
=====

Vireo is a media player for Windows with a redesigned interface. It is built
on VLC media player: the playback engine, the codecs and the plugins are VLC's.
Vireo is an independent project and is not affiliated with or endorsed by
VideoLAN.

Vireo can be installed next to VLC media player. It has its own program
folder, its own settings (%APPDATA%\vireo) and its own file-type registrations,
and it never reads, changes or removes the settings of a VLC installation.
